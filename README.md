## Overview

**SustainWear** needs a responsive web-based platform, that is aimed at promoting sustainability through structured clothes donation.

Key features include:
- 🧑‍🤝‍🧑 Role-based dashboards for donors, charity staff, and system administrators  
- ♻️ Sustainability goal tracking  
- 📦 Inventory management and donation tracking  
- 🤖 AI-powered clothing categorisation (via external API)  
- 📱 Responsive design for accessibility on all devices  

---

## ✨ Features

- 👤 **User Roles** *(planned)*: tailored dashboards for donors, charities, and admins  
- 🗃️ **Donation Management** *(planned)*: track donated clothes, status, and condition  
- 📊 **Analytics** *(planned)*: sustainability progress and redistribution statistics  
- 🤖 **AI Categorisation** *(planned)*: automatic clothing type, condition, and season categorisation  
- 🛠️ **Tech Stack**: Laravel, PHP, SQLite3, CSS, JS
